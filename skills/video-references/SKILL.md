# video-references

Not an expert: the shared memory of the pack. Read the file you need.

| File | Read when |
|---|---|
| `working-agreement.md` | start of every session; defines `.video/`, `brief.md`, defaults, the rules |
| `design-rules.md` | designing or reviewing any scene |
| `style-presets.md` | choosing or resolving a style into `theme.json` |
| `formats.md` | picking a size, re-laying out for vertical, encoding and loudness |
| `scene-patterns.md` | storyboarding or building: the proven scene types and their timings |
